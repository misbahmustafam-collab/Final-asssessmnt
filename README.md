## 📊 Final Assessment

A comprehensive end-to-end **Data Science, Machine Learning & Deep Learning** project built with Python.

This final assessment analyzes historical stock-market data of **Adobe (ADBE), Microsoft (MSFT), Oracle (ORCL), and Salesforce (CRM)** using data cleaning, exploratory data analysis, feature engineering, statistical analysis, machine learning, anomaly detection, market-regime clustering, Monte Carlo simulation, and deep learning.

### 🤖 Key Areas Covered

* Data Cleaning & Validation
* Exploratory Data Analysis
* Statistical & Risk Analysis
* Technical Feature Engineering
* Classification & Regression
* Random Forest & Logistic Regression
* PCA & K-Means Clustering
* Anomaly Detection using Isolation Forest
* Monte Carlo Simulation
* Neural Networks
* LSTM Deep Learning
* Data Visualization

### 🛠️ Technologies

**Python • NumPy • Pandas • Matplotlib • Seaborn • SciPy • Scikit-learn • TensorFlow • Keras**

### 🎯 Learning Outcomes

This project demonstrates practical experience in **data analysis, feature engineering, supervised and unsupervised learning, regression, classification, clustering, anomaly detection, neural networks, LSTM, and end-to-end analytical workflows.**
